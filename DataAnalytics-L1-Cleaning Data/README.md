# Data Cleaning

## Project Overview
This project focuses on cleaning and preprocessing a dataset using Python and Pandas.

## Objectives
- Identify and handle missing values
- Remove duplicate records
- Check and correct data types
- Identify and handle inconsistent data
- Prepare a clean dataset for further analysis

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab

## Project Workflow
1. Load and inspect the dataset
2. Check for missing values
3. Check for duplicate records
4. Clean and transform the data
5. Validate the cleaned dataset
6. Save the cleaned data for further use

## Files
- 'CleaningData.ipynb' — Complete data cleaning analysis and code
- 'README.md' — Project documentation
