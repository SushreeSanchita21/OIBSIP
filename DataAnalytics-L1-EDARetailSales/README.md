# EDA Retail Sales Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, customer demographics, 
product performance, and business insights.
## Objectives
- Analyze the retail sales dataset
- Handle missing values
- Study sales trends over time
- Analyze customer demographics
- Analyze product categories
- Identify correlations between numerical variables
- Generate business insights and recommendations
## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
## Key Analysis
The project includes:
- Data cleaning
- Descriptive statistics
- Monthly and quarterly sales analysis
- Gender distribution
- Age group distribution
- Category analysis
- Correlation heatmap
- Business recommendations
## Conclusion
The analysis helps identify important sales patterns, customer characteristics, and product performance that can support 
better business decisions.
